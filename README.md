# Mutual Match: будет ли взаимная симпатия?

Учебный ML-проект: бинарная классификация взаимного match по взаимным оценкам участников speed dating.

## О проекте

После короткой встречи участники speed dating заполняют анкету с оценками партнёра и решением, хотят ли увидеться снова. В проекте финальные решения и близкие к ним субъективные поля исключаются, а модель ретроспективно связывает взаимные оценки с итоговым `match`.

**Цель:** Разработать модель бинарной классификации и ретроспективный демонстрационный сервис, который по взаимным оценкам оценивает вероятность зафиксированного в эксперименте match.

## Данные

Открытая CSV-версия Speed Dating с DataHub: 8 378 строк, 123 поля, готовый target `match`. Набор основан на экспериментах Columbia Business School (2002–2004).
